Dev Station — Example UI Mockups

Three static reference screens generated from docs/Product_Specification.md: Project Dashboard, AI Agent Session, and Git Review & Commit. AI sessions are not a custom chat UI — the app spawns and attaches to the actual agent CLI (claude, cursor-agent, etc.) in an embedded, controllable terminal. No toasts or notification center — when agents finish across multiple projects at once, it only shows up as badges on the project list (left) and entries in the activity/status bar (bottom).
