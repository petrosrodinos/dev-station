# Frequently Asked Questions

## Is this another code editor?

Not exactly.

It includes a basic code editor for when you need to inspect or modify files, but the main focus is managing AI coding agents, terminals, project previews, Git, scripts and development workflows.

## What AI coding agents does it support?

The workspace is designed to work with existing coding agents such as Claude Code, Codex and Cursor, rather than requiring you to use a proprietary AI agent.

Support can expand as new coding agents become available.

## Can I work on multiple projects?

Yes. You can keep multiple projects available and switch between them quickly.

## Can I run multiple AI agents at the same time?

Yes. Each agent can have its own session and project context, allowing you to work on multiple tasks concurrently.

## Can I preview my application?

Yes. Local development servers can be opened in the built-in browser preview so you can see the application alongside your agent session.

## Does it work with Git?

Yes. Git functionality is built into the workspace so you can inspect repositories, branches and changes without leaving the application.

## Does it detect project scripts?

Yes. The workspace can detect common project configuration and surface available development scripts so you can run them directly.

## Do I have to stop using my existing code editor?

No.

The product is designed to complement your existing development tools. You can continue using whatever editor or AI coding agent fits your workflow.

## Who is this for?

It's primarily designed for developers who use AI coding agents and regularly work across multiple projects, repositories, terminals and application previews.
